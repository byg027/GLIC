# Directrices del Usuario y Preferencias

- **NO usar el subagente de navegador (`browser_subagent`) para comprobar cambios en el sitio web.**
- Aplicar los cambios en el código de forma directa y rápida, esperando el feedback del usuario para validar los resultados en lugar de abrir el navegador automatizado.
- **NO usar NUNCA emojis en este proyecto.** Bajo ninguna circunstancia se deben utilizar emojis en ninguna parte de la web. Utilizar siempre texto limpio, entidades HTML estándar (como viñetas `&#9679;`) o iconos SVG vectoriales.
